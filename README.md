# OvertheCloud — visionOS DocC Tutorial

구름 위를 둥둥 떠다니는 Immersive Space를 만드는 visionOS 기초 튜토리얼입니다.
SwiftUI와 RealityKit을 사용해 프로젝트 준비부터 에셋 로딩, 구름 애니메이션,
메인 윈도우와 몰입 공간 전환까지 단계별로 구현합니다.

Build an immersive visionOS environment above the clouds with SwiftUI and RealityKit.
Follow the tutorial from project setup and asset preloading to cloud animation and space transitions.

## 학습 내용 · What you'll build

1. 프로젝트와 에셋 준비 · Set up the project and assets
2. 상태 모델 설계 · Model shared app state
3. 에셋 프리로딩과 캐싱 · Preload and cache assets
4. 몰입 공간 콘텐츠와 구름 애니메이션 · Build and animate immersive content
5. 메인 윈도우 UI와 공간 전환 · Build the main window and space transitions
6. 앱 진입점 구성과 완성 영상 · Connect the app and explore the finished result

## 준비 사항 · Requirements

- Xcode 26 or later
- visionOS 26 or later
- Download `OvertheCloud-Assets.zip` from **Project files** in Chapter 1.

Apple Vision Pro가 없어도 Simulator에서 테스트할 수 있습니다.
공간의 깊이감과 몰입감을 온전히 경험하려면 실제 기기가 필요합니다.

You can test the app in Simulator without Apple Vision Pro. Run it on a device
to fully experience the depth and immersion of the space.
